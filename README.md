# shap-sbcas26

Material do minicurso **Interpretação de Modelos de Aprendizado de Máquina Aplicados à Saúde com SHAP**, preparado para o SBCAS 2026.

**Autores:** Letícia Martins Raposo e Vinicius Navega Stelet  
**Tema:** interpretabilidade, explicabilidade, valores de Shapley e uso de SHAP em modelos preditivos aplicados à saúde.

## Objetivo

Este repositório organiza o material teórico e prático do minicurso. O foco é mostrar como utilizar SHAP para interpretar modelos de aprendizado de máquina em dados clínicos tabulares, com atenção explícita às limitações metodológicas, à diferença entre explicação preditiva e inferência causal, e às implicações éticas e regulatórias em saúde.

## Público-alvo

O material foi pensado para estudantes, pesquisadores e profissionais de computação aplicada à saúde, ciência de dados, bioinformática, epidemiologia computacional e áreas correlatas. É recomendável familiaridade básica com aprendizado de máquina supervisionado, classificação binária e métricas de avaliação.

## Base de dados

O exemplo prático usa o arquivo cardio_train.csv, do conjunto Cardiovascular Disease Dataset, disponível no Kaggle: https://www.kaggle.com/datasets/sulianova/cardiovascular-disease-dataset

O arquivo de dados também está incluído neste repositório.
